# 📜 Касым-бот — Учебный помощник по Истории Казахстана

Telegram-бот для **одного учебного чата** по Истории Казахстана.  
Модерация · ИИ · Блиц-опросы · Книги · Геймификация

---

## 🚀 Быстрый старт

### 1. Клонируй проект
```bash
git clone <repo>
cd kasym_bot
```

### 2. Установи зависимости
```bash
pip install -r requirements.txt
```

> Для OCR (сканированные PDF) нужен Tesseract:
> - Ubuntu: `sudo apt install tesseract-ocr tesseract-ocr-rus poppler-utils`
> - macOS: `brew install tesseract poppler`

### 3. Создай .env файл
```bash
cp .env.example .env
```

Заполни значения:
```
BOT_TOKEN=         # токен от @BotFather
OWNER_ID=          # твой Telegram ID
MAIN_CHAT_ID=      # ID учебного чата (см. ниже)
REQUIRED_CHANNEL=  # @channel (или оставь пустым)
OPENAI_API_KEY=    # ключ OpenAI (gpt-4o-mini + Whisper)
```

### 4. Запуск
```bash
python main.py
```

## 🔑 Как узнать ID чата и владельца

**OWNER_ID** — перейди в @userinfobot, он покажет твой ID.

**MAIN_CHAT_ID:**
1. Добавь бота в чат как администратора
2. Напиши любое сообщение в чат
3. Открой: `https://api.telegram.org/bot<TOKEN>/getUpdates`
4. Найди поле `"chat": {"id": -100XXXXXXXXX}` — это и есть ID

## 📚 Загрузка книг

1. Напиши боту в **личные сообщения**
2. Отправь файл PDF, DOCX или TXT
3. Бот автоматически:
   - Извлечёт текст
   - Разобьёт на фрагменты
   - Сохранит в базу знаний
   - Сообщит о результате

Если PDF сканированный — бот попробует OCR автоматически.

**Команды для книг (в ЛС):**
```
Книги                    — список книг
Книга удалить 3          — удалить книгу №3
Книги очистить           — удалить все книги
```


## 🛡 Как работает модерация

### Автоматически проверяет:
| Тип | Реакция |
|-----|---------|
| Мат в тексте | Удалить + временное ограничение |
| 18+ контент | Удалить + временное ограничение |
| Флуд (5+ сообщений за 6 сек) | Предупреждение → мут 5 мин |
| Спам одинаковыми сообщениями | Удалить + предупреждение |
| Капслок | Предупреждение (без удаления) |
| Спам эмодзи (10+) | Удалить + предупреждение |
| Спам стикерами (4 за 15 сек) | Предупреждение |
| Мат в голосовом (Whisper) | Удалить + ограничение |

### Карточка нарушения в ЛС:
Владелец получает уведомление с кнопками:
- 🗑 **Удалить** — кик + бан + банлист
- ⚠️ **Варн** — предупреждение + снять ограничение
- 🔇 **Ограничить** — запросить время и ограничить
- 😇 **Простить** — снять ограничение без наказания

### Анонимность администрации:
В чат пишется: `«Администрация решила...»` — имя владельца не раскрывается.

## 🧠 ИИ по Истории Казахстана

Участники пишут:
```
Бот, кто такой Абылай хан?
Бот, в каком году образовалось Казахское ханство?
Касым, объясни тему Жузов
```

Бот:
- Ищет ответ в загруженных книгах
- Отвечает с указанием книги и страницы
- Адаптирует стиль под каждого пользователя
- Помнит контекст разговора (последние 6 обменов)

**Формат ответа:**
```
📘 Ответ:
...текст...

📚 Источник:
Книга: История Казахстана
Страница: 47
```

## ⚡ Блиц-опросы

**Команды в чате:**
```
Блиц              — запустить вопрос
Блиц стоп         — остановить (модератор/владелец)
Топ блица         — таблица лидеров
Мой уровень       — моя статистика и XP
Моя статистика    — подробно
Топ / Топ недели  — лидерборд
```

**Правила:**
- Засчитываются только первые **два** правильных ответа
- 1-й: +5 XP | 2-й: +3 XP | Участие: +1 XP
- Бот проверяет ответы через ИИ (семантически)
- Таймаут: 60 секунд

## ❓ Частые вопросы

**Бот не отвечает на вопросы по истории?**  
→ Загрузите книги в ЛС бота. Без книг ИИ не работает по теме.

**Нет расшифровки голосовых?**  
→ Нужен `OPENAI_API_KEY` в .env.

**OCR не работает?**  
→ Установите Tesseract: `sudo apt install tesseract-ocr tesseract-ocr-rus poppler-utils`

**Бот игнорирует команды?**  
→ Убедитесь, что `MAIN_CHAT_ID` совпадает с реальным ID чата.
